# BuffRates-OG

Buffs following mob spawn and drop rates:

- Slimes
- Raiders
- Zombie iron drops

Buffs following mob health and strength (to compensate for 1.8 combat system)

- Wardens

Gradle Version: 8.14.3

Java Version: GraalVM CE 17.0.9

Minecraft API: Purpur 1.19.4
